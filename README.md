\# EduLearn 📚



EduLearn is an Android-based learning application designed for college students.



The application allows students to learn programming subjects, read lessons, take quizzes, track their progress, and earn achievements.



\## 🚀 Features



\- 🔐 Student Registration and Login

\- 📚 Dynamic Subject Management

\- 📖 Lesson Content

\- 📝 Quiz System

\- 🤖 AI-based Automatic Quiz Generation

\- 📊 Student Progress Tracking

\- 🏆 Achievements and Points

\- 👤 Student Profile

\- 🌙 Dark Mode

\- 🔥 Firebase Authentication

\- 🗄️ Room Database

\- 📱 Android Application
